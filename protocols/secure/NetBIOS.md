netbios is an API and a set of networking protocols for providing communication services over a local netowrk. It's used primarily to allow applications on different computers to find and interact with each other on a network
NetBIOS allows for three primary services
- Name service (NetBIOS-NS): allows computers to register, unregister, and resolve names in a local network
- Datagram service (NetBIOS-DGM): Supports connection-less communication and broadcasting
- Session Service (NetBIOS-SSN): Supports connection-oriented communicaiton for more reliable data transfers
