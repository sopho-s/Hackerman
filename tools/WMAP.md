WMAP is a powerful, feature rich web application vulnerability scanner that can be used to automate web server enumeration and scan web applications for vulnerabilities
it is used within msf console

```shell
load wmap
```
# wmap_sites
can add, delete, and list sites
# wmap_targets
defines the target url you wish to perform the vulnerability scan on
# wmap_run
runs wmap
# wmap_vulns
displays all vulnerabilities found by wmap
