# On disk
## Obfuscation
obfuscation reorganises code in order to make it harder to analyse
## Encoding
Encoding is where you change the data into a new format using a scheme which can be reversed at a later point
## Packing
Generates a new binary structure with a smaller size and therefor provides the payload with a new signature
## Crypters
Encrypts code or payloads and decrypts the encrypted payload in memory
## Shellter
shelter is a tool that allows you to almost completely hide on disk viruses from antiviruses
